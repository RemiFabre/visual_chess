# Visual Chess

We're prototyping richer board visualizations for chess beginners: who controls each square, where attack lines run, which pieces are pinned ("iced", SFX coming soon), which pieces are hanging.

See [STATUS.md](STATUS.md) for current state, screenshots, and notes.

## Run locally
```bash
open index.html
```
No build step. Vanilla HTML + ES modules, pieces come from the bundled Lichess SVG set in `vendor/lichess/cburnett/`.
